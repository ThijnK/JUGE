# MAZE Raw Benchmark Results

All of the raw data used in the evaluation of MAZE is available in two zip files:

- [maze_benchmarks_synth.zip](/maze_benchmarks_synth.zip) contains the results of the benchmarks for the synthetic benchmark set, for MAZE with different search strategies, as well as EvoSuite and Randoop.
- [maze_benchmarks_open.zip](/maze_benchmarks_open.zip) contains the results of running MAZE using FOS+COS on the open source benchmark set.

Please refer to the [README](/maze_benchmarks/README.md) for details on how to replicate the benchmarks and how to analyze the results, including calculating rankings, performing the Friedman test, and more.
Additional post-processing scripts used specifically for the MAZE evaluation—complementing the original data processing scripts in the JUGE repository—are available in the [scripts](/maze_benchmarks/scripts) subdirectory.
