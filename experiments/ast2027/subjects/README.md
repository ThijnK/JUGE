# Subject snapshot

These twenty Java sources are copied without changes from
[MAZE revision eb9c3da](https://github.com/ThijnK/maze/tree/eb9c3da/src/main/java/nl/uu/maze/benchmarks).
They are experiment inputs, separate from the packaged engine. JUGE compiles them
with Java 8 and records hashes of both sources and bytecode in each manifest.
The original source project is MIT licensed; see `LICENSE-MAZE` here.
Historical Ackermann sources had fewer branches; historical coverage values are
not directly comparable to coverage on this snapshot.
